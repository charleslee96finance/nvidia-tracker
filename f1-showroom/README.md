# F1 暗夜车库实景 3D

法拉利 F1-75（蒙扎特别涂装）× 迈凯伦 MCL39 × 红牛 RB21 三车互动 3D 展厅，**双场景一键切换**：

- 🏜️ **摩洛哥赛道**（默认）—— 马拉喀什街道赛风格：三车发车格与黑白起步线、
  红白路肩、起步灯架、赭红城墙与马蹄拱门、棕榈树、摩洛哥国旗、观众看台、
  阿特拉斯雪山背景。可切换 **☀️ 正午 / 🌅 黄昏 / 🌙 夜战** 三种时段
  （黄昏金色斜阳、夜战泛光灯架 + 星空，光照与天空整体联动）
- 🌃 **暗夜车库** —— 对照实拍照片还原：链条吊挂灯管（三车各一组聚光光池）、
  高反光水泥地、门洞体积光

车身涂装对照实拍照片，1:1 实车比例；全部车体与场景为 three.js 程序化建模，
**零外部资源**，无需联网。

## 功能

- **360° 自由旋转**：拖动环绕、滚轮/双指缩放、右键平移，支持自动旋转展示
- **四种视角**：
  - **360° 环绕**
  - **驾驶舱**：坐进座舱，眼前是 halo 保护圈与方向盘仪表屏
    （动态转速灯条 / 档位 / 车速 / ERS 电量 / DRS / 圈数实时模拟）
  - **📹 车载 T-cam**：车手头顶进气箱上的经典转播机位，halo 中柱居中、俯瞰赛道
  - **🚁 航拍**：赛道上是直升机高空盘旋（拖动绕场 / 调高度，滚轮推拉），
    车库里是顶棚吊臂机位
- **分层结构**：完整车身 / X 光透视 / 拆解引擎 —— 引擎盖上掀、侧箱滑出、鼻锥前移，
  露出 V6 涡轮混动引擎、涡轮增压器、排气歧管、变速箱、散热器、
  ERS 电池组、MGU-K 等内部细节（中英标注）
- 点击任意一辆赛车即可聚焦；地面指示牌与右下角参数卡对应当前车辆
- **🚦 起跑**（赛道场景）：五盏红灯依次亮起 → 随机熄灭 → 三车并驾加速冲出直道；
  每次起跑抓地随机，谁领先看临场发挥。镜头随视角而变：环绕视角为后方跟拍、
  航拍视角为直升机跟拍、**驾驶舱 / T-cam 视角则随所选赛车一起起跑**
  （路面震动 + 速度感视野，仪表屏显示真实车速与档位）
- **🔧 进站换胎**（赛道场景）：所选赛车以 80 km/h 限速驶入维修位急停 →
  16 人机组（四角各一名风炮手 / 拆胎手 / 装胎手 + 前后千斤顶 + 两名扶车手）
  抬车、拆装四轮、放车 → 放行灯转绿出站。
  - 车队配色机组服、车队色维修位地标、风炮“哒哒”声（声浪开启时）
  - 右上角转播风格计时：停车时间（每次 1.9–2.5 s 随机）+ 评级 + 换胎配方
    （如 中性胎 → 软胎，胎壁色圈随之切换）
  - 实时播完自动换机位 **0.4× 慢放回放**（顶视俯拍四角同步作业），结束自动复位
  - 驾驶舱 / T-cam 视角下进站，以车手视角看机组围上来
- **🔊 引擎声浪**：Web Audio 实时合成 V6 涡轮声，音高/音量跟随仪表盘转速与
  油门变化（起跑升档轰鸣、进站限速器嗡鸣），可一键开关
- **细节动画**：DRS 襟翼随 DRS 区开合、排气口热浪扰动、起跑时车轮转动 + 前轮微摆、
  后轮起步扬沙尾流、进站时仪表屏闪烁 PIT LIMITER
- **📷 拍照模式**：一键隐藏全部界面，留下干净画面；可保存当前视角为 PNG 壁纸
  （Esc 退出）
- **中 / 英双语**：面板 🌐 按钮一键切换（界面、参数卡、引擎标注、进站计时全部翻译，
  选择会记住）

## 分享链接参数

在地址后加 `#` 参数可直达指定状态（可组合，用 `&` 连接）：

| 参数 | 作用 |
| --- | --- |
| `car=ferrari` / `mclaren` / `redbull` | 聚焦指定赛车 |
| `view=orbit` / `cockpit` / `tcam` / `aerial` | 指定视角 |
| `scene=track` / `garage` | 指定场景 |
| `time=noon` / `sunset` / `night` | 指定赛道时段 |
| `lang=en` | 以英文打开 |
| `th=-0.55&phi=1.35&r=9` | 固定环绕机位（方位 / 俯仰 / 距离） |

例：`index.html#car=mclaren&view=tcam&time=sunset`

## 使用

直接用浏览器打开 `index.html` 即可（纯静态、非模块脚本，支持 file:// 协议）。

也可以起一个本地服务：

```bash
cd f1-showroom
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```
